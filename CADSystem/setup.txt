1. Общие требования
___________________
    a) Убедитесь в наличии полномочий администратора. 
    б) Остановите выполнение антивирусных программ.
    в) Откройте компонент «Система». Выберите пункт "Дополнительные 
параметры системы". На вкладке "Производительность" нажмите кнопку 
"Настройка". На вкладке "Предотвращение выполнения данных" выберите 
команду "Включить DEP для основных программ и служб Windows".
    г) Введите в поле поиска Windows MSCONFIG и запустите найденную 
программу. На вкладке "Сервис" выберите параметр "Настройка контроля 
учетных записей (UAC)". Нажмите кнопку "Запуск".  Установите "Никогда 
не уведомлять". Нажмите ОК, закройте средство MSCONFIG. 
    д) Программу установки необходимо запускать из проводника Windows 
с повышением привилегий (Запуск от имени администратора).
    ж) После установки при необходимости запустите антивирус, включите 
DEP и UAC
    з) При выполнении "Однопользовательской" и "Клиентской" инсталляций 
в случае установки Cadmech, до начала установки на ПК должна быть 
установлена необходимая CAD система и один раз запущена под пользователем 
с правами администратора.


2. Однопользовательская инсталляция
___________________________________
   a) Вставьте ключ аппаратной защиты в порт компьютера.
   б) Запустите файл Setup_CAD_IPS.exe из корневого каталога USB Flash.
   в) Укажите директорию, в которой будут установлены системы, например,
C:\IM.
   г) Укажите директорию, в которой будет хранится база данных Search 
(если Search входит в комплект поставки). Необходимо зарезервировать 
достаточно свободного места на этом диске для увеличения базы данных 
Search. 
   д) В следующем диалоге инсталлятора укажите папку, в которой будут 
располагаться иконки для быстрого вызова программ. Эта папка будет 
помещена в меню Windows Пуск|Программы  (Start|Programs). После этого 
начнется установка программ на Ваш компьютер.
   ж) Запустите хотя бы один раз программу SEARCH.
   з) Запустите хотя бы один раз программу IMBASE.
   и) Запустите хотя бы один раз программу AVS.
   к) Запустите хотя бы один раз программу Cadmech.
   л) Приступайте к работе.


3. Серверная инсталляция
________________________
   Серверная инсталляция производится при многопользовательской работе в 
сети на компьютере, выполняющем роль сервера в Вашей сети. Данная 
инсталляция производится только если у Вас имеется именно серверная 
инсталляция и сетевой ключ.
   Проверьте качество работы сети. Инсталляцию имеет смысл проводить
только если Вы уверены в правильной работе Вашей сети. 
   а) Запустите файл Setup_CAD_IPS.exe из корневого каталога USB Flash.
   б) Укажите директорию, в которой будут установлены системы, например, 
C:\IM.
   в) Укажите директорию, в которой будет храниться база данных Search 
(если Search входит в комплект поставки), например, D:\DATABASE.
Необходимо зарезервировать достаточно свободного места на этом диске для
 увеличения базы данных Search. Для увеличения быстродействия системы 
желательно разместить программы и его базу данных Search на разных дисках.
   г) Введите сетевое имя Вашего сервера. Затем будет произведена 
установка Search на Ваш сервер.
   д) После завершения инсталляции вставьте ключ аппаратной защиты в порт 
компьютера, перегрузите машину.
   ж) Откройте общий доступ к папке установки.
   з) НЕ ЗАПУСКАЙТЕ программы непосредственно из серверной папки, а 
переходите к установке клиентской части.
   и) Для успешного запуска менеджера лицензий на Windows 2008 Server R2 и
выше необходимо настроить DEP.
Откройте компонент «Система». Выберите пункт "Дополнительные параметры 
системы". На вкладке "Производительность" нажмите кнопку "Настройка". На
вкладке "Предотвращение выполнения данных" выберите команду "Включить DEP
для основных программ и служб Windows", или нажмите кнопку "Добавить".
Перейдите к папке Common, выберите ImLicSv4.exe (служба менеджера или 
imlic4.exe для запуска приложения менеджера) и нажмите кнопку Открыть.
Нажмите кнопку ОК, затем нажмите кнопку ОК в диалоговом окне Свойства 
системы (если оно появится). После этого нажмите кнопку ОК еще раз.
Чтобы изменения вступили в силу, потребуется перезагрузить компьютер.
   к) На сервере лицензий должны быть открыты порты:
Для подключения к менеджеру лицензий "Intermech License Manager" 
используется порт (TCP) 1980, для htp монитора 8989.
Для подключения к менеджеру лицензий "Intermech License Manager 4.0" 
используется порт 1982,  для htp монитора 8990.
Для подключения к менеджеру лицензий "Intermech License Manager 5.0" 
используется порт 1985, для htp монитора 8995.

При сетевой поставке с большим количеством лицензий может предоставляться 
запасной ключ. При выходе из строя основного ключа ОДО "ИНТЕРМЕХ" 
передает заказчику программу и коды активации запасного ключа.


4. Клиентская инсталляция
_________________________
   Клиентская часть программ устанавливается на рабочих станциях при 
многопользовательской работе в сети.
   Перед ее установкой нужно должна быть выполнена установка серверной 
части программ (см. п.2) и на сервере сделать доступной в сети директорию 
установки. 
   а) На клиентской машине запустите файл Setup_CAD_IPS.exe с сервера, где 
расположена серверная инсталляция, например, \\Ntserver\IM\Setup_CAD_IPS.exe.
   б) В следующем диалоге инсталлятора укажите папку, в которой будут 
располагаться иконки для быстрого вызова программ. Эта папка будет 
помещена в меню Windows Пуск|Программы  (Start|Programs). После этого
начнется установка программ на Ваш компьютер.
   г) После завершения инсталляции перегрузите машину.
   ж) Запустите хотя бы один раз программу Cadmech.
   з) Приступайте к работе.

Назависимо от выбора типа установки (с копированием исполняемых файлов на 
клиента или нет) приложения PDBrowser, IMShape, Cadmech NX всегда 
копируются на клиента! 

5. О настройках программы установки и программы автообновления клиентов 
см. в папке DOC файл Setup&AutoSetup.rtf

6. При установке под СУБД MSSQL или ORACLE необходимо произвести их 
настройку. Более подробно смотрите на DVD в папке DataBase файлы 
mssqlReadMe.pdf и oraReadMe.pdf


7. Удаление программ
____________________
Выполните из панели управления удаление программы "Intermech". Удалите
папку IM с оставшимися файлами, которые были создано в процессе работы
программ.


8. Переход на новые версии ПО
_____________________________

   а) Выполните установку нового ПО в папку предложенную программой Setup. 
   б) В случае наличия новой версии Search выполните программу Impatch.exe из
папки:
   - Search\upgrade\interbase, для СУБД Firebird;
   - Search\upgrade\mssql, для СУБД MSSQL;
   - Search\upgrade\oracle, для СУБД FOracle.
   в) В случае наличия новой версии Techcard выполните программу TCPatch_Win32.exe
из папки Techcard\Upgrade. Для более ранних версий базы используйте TCPatch.exe, 
который находится в дополнительных папках. Название доп. папки соответсвует версии базы.
Например, для обновления до версии 857, запустите TCPatch.exe из папки "797-857".
   г) Выполните установку клиентской части требуемого ПО на рабочие станции
в случае многопользовательской версии.
